Update the relevant spec files in `docs/` before or alongside any code change.

**Why:** The project CLAUDE.md explicitly requires this: "Before a change update respective specs in docs/"

**How to apply:** For any UI, engine, or client change, identify the relevant doc(s) in `conspiracy-game/docs/` (e.g., `ui.md`, `panels.md`, `map.md`) and update them as part of the same change — not as an afterthought.
